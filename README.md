## Description

This website serves as an online presence for Craft, featuring multiple pages including Home, Pages, Portfolio, and About Us. Built with modern web technologies, it incorporates responsive design principles, smooth animations, and user-friendly navigation to provide an engaging experience for visitors interested in cafes, coffee shops, and bars.

## Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices using Bootstrap.
- **Smooth Scrolling**: Implemented with Lenis library for a fluid user experience.
- **Parallax Effects**: Dynamic visual elements that respond to scroll events.
- **Interactive Navigation**: Fixed header with social media links and contact information.
- **Modern UI**: Clean, professional design with animations powered by Animate.css.
- **Multi-page Layout**: Separate pages for different sections of the site.
- **SEO Friendly**: Proper meta tags and semantic HTML structure.

## Built With

- **HTML5** - Structure and content
- **CSS3** - Styling and layout
- **JavaScript** - Interactivity and animations
- **Bootstrap 5.3.8** - Responsive framework
- **Font Awesome 7.0.1** - Icons
- **Animate.css 4.1.1** - CSS animations
- **Lenis** - Smooth scrolling library

## Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No server-side dependencies required

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd semi-final
   ```

2. Open the project in your preferred code editor.

3. No additional dependencies are required as all libraries are linked via CDN.

## Usage

1. Open `index.html` in your web browser to view the homepage.
2. Navigate through the site using the menu links:
   - Home (`index.html`)
   - Pages (`pages.html`)
   - Portfolio (`portfolio.html`)
   - About Us (`about.html`)

3. For development, you can serve the files locally using any static server or simply open the HTML files directly in a browser.
